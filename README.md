# JAWELEVEN для DLE 21.0

Светлый адаптивный шаблон блога и новостного сайта. Проверенная версия CMS: DataLife Engine 21.0.

## Возможности

- Карточки публикаций с постером, категориями, тегами и пагинацией.
- Мобильное меню, поиск, вход и формы DLE.
- Полная статья, комментарии, закладки, профиль и диалоги личных сообщений.
- Статистика сайта и таблица авторов.

## Адаптация

Исправлены теги, пути, формы, рейтинг профиля и таблица статистики. Убраны обращения к отсутствующим модулям и ненужные библиотеки. Bootstrap 4.6.2 хранится локально; jQuery поставляет CMS. Тёмная тема, магазин и платёжные модули не заявляются.

## Установка

Скопируйте JAWELEVEN в templates, выберите шаблон в DLE и очистите кеш. Требуется дополнительное поле poster типа «Изображение». Подробности в INSTALL.md. CMS и база в репозиторий не включены.
